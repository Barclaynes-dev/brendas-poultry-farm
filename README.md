# Brenda's Poultry Farm – Egg Production Tracking System

## 1. Project Overview

The Egg Production Tracking System is a proposed smartphone-based system designed for Brenda's Poultry Farm, located in Muyenga, Kampala, Uganda.

The project focuses on improving how daily egg production is recorded and monitored at the farm. Currently, production information is recorded manually in counter books. This method can lead to calculation errors and make it difficult to track production accurately over time.

The proposed system will provide a simple way to record daily egg production, calculate totals automatically and view production records and reports.

## 2. Problem Statement

The farm currently uses manual counter books to record the number of eggs collected each day. Although this method provides a record of production, manual calculations can result in errors, making it difficult to obtain accurate daily and weekly production totals.

The proposed system aims to reduce these errors and make production records easier to manage.

## 3. Project Objectives

The main objectives of the project are to:

- Provide a digital method of recording daily egg production.
- Record intact and damaged eggs separately.
- Automatically calculate daily and weekly production totals.
- Allow authorised users to view saved production records.
- Make production information easier for the farm owner to monitor.

## 4. Project Scope

The system will focus specifically on egg production tracking.

**Included:**
- User access.
- Recording daily egg production.
- Recording intact and damaged egg counts.
- Automatic calculation of production totals.
- Viewing daily and weekly production reports.

**Not included:**
- Sales management.
- General farm inventory management.
- Poultry health management.

## 5. Proposed System Users

- **Record-Keeping Worker:** Enters daily egg production figures into the system.
- **Farm Owner (Brenda):** Reviews production records and monitors daily and weekly totals.

Poultry workers are responsible for collecting, sorting and counting the eggs before the figures are entered into the system.
